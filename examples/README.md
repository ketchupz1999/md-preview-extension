# 本地文档阅读器 · 设计笔记

> 把散落在文件夹里的 Markdown，变成一个安静的阅读空间。\
> 产品设计 · 交互约定 · 2026-09-10

## 1. 从阅读开始

文档已经在电脑上，打开就能阅读。保留原有的目录组织方式，用大纲定位当前章节。

**一个文件夹、一列目录、一页正文。** 打开项目后，先看到 README；想读另一份文档，直接从左侧切换。文件树和文档大纲各有位置，内容始终占据主要空间。

- **目录浏览**：按需展开，保留原本的文件组织方式。
- **章节导航**：点击大纲，直接到达想读的那一段。
- **本地更新**：编辑器保存后，阅读器自动显示新内容。

## 2. 做减法的界面

工具放在边缘，文字留在中间。用留白区分内容层级，用一抹蓝色标记当前所在的位置。

| 区域 | 职责 | 交互 |
| --- | --- | --- |
| 左侧导航 | 浏览文件与章节 | 文件 / 大纲切换 |
| 阅读区域 | 展示文档内容 | 本地链接、代码高亮 |
| 顶部工具栏 | 控制阅读方式 | 字号、主题、源码 |

### 2.1 阅读节奏

段落之间保持呼吸感。长标题可以自然换行，代码和表格只在自己的区域内横向滚动。

### 2.2 文档之间的连接

从这里打开[离线与隐私](notes/离线与隐私.md)，或跳到[验证清单](notes/验证清单.md#验证清单)。文件网址模式按本机路径解析相对链接；手动选择文件夹时，引用限制在所选文件夹内。

[时序图与流程图示例](notes/图表与时序.md)也可以直接离线阅读，长图支持放大查看。

## 3. 文件留在设备上

```javascript
const reader = {
  access: 'read-only',
  network: false,
  directoryExplorer: 'enabled',
};
```

不加载外部字体、图片或脚本。文档中的外部网址仍然可读，点击时只复制地址。
