MD Preview automatically previews local Markdown in your browser. Read project documentation, technical notes, and your personal knowledge base with clear formatting and easy navigation.

Features

• Markdown formatting: headings, tables, task lists, and syntax-highlighted code.
• Document navigation: an outline, a local file tree, and filename search.
• Mermaid diagrams: sequence diagrams, flowcharts, and more, with an enlarged view.
• Flexible layout: content fills the reading area at any browser zoom, with horizontal scrolling for wide tables.
• Reading tools: light and dark themes, source view, adjustable text size, automatic refresh, and reading-position recovery.
• Related files: static HTML previews with supported local CSS and images, plus color swatches in CSS files.

Local by design

All processing happens on your device. MD Preview reads files without changing them and does not upload documents or load remote scripts, fonts, or images. Your recent local file reference, reading position, and preferences stay in browser-local storage. Document bodies are not persistently cached. External Markdown links can be copied; HTML previews do not run scripts or navigate to other pages.

Getting started

After installation, open the extension's Details page and enable “Allow access to file URLs.” Then open a local Markdown file in Chrome, or click the extension icon to choose a file or folder.

The extension interface is currently in Simplified Chinese. Documents can contain any language. Online documents, interactive scripts, and math typesetting are not supported.
