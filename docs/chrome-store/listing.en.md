# MD Preview

Read local Markdown directly in your browser.

Enable file URL access once, then open a .md file to see a formatted preview. Use the outline to jump between sections and the file explorer to move through your local documents. Rendering happens on your device.

Features

• Markdown headings, tables, blockquotes, task lists, and syntax-highlighted code.
• A compact outline, a separate local file explorer, and filename search.
• Locally rendered Mermaid sequence diagrams, flowcharts, state diagrams, and ER diagrams, with an enlarged view.
• Light and dark themes, source view, text-size settings, automatic refresh, and reading-position recovery.
• Static previews of related local HTML notes, including supported local CSS and images. CSS files include color swatches.

Local operation

MD Preview reads files without changing them. It does not upload documents, connect to a developer server, or load remote scripts, fonts, or images. Rendering libraries are bundled in the extension. External Markdown links can be copied, while HTML preview scripts and navigation are disabled.

Getting started

Open the extension's Details page and enable “Allow access to file URLs,” then open a local Markdown file in the browser. You can also open a file or folder from the extension toolbar.

⌘ / Ctrl + K: Find a file
⌘ / Ctrl + B: Toggle the sidebar
Esc: Close an enlarged diagram

The current interface is in Simplified Chinese. Supported Markdown extensions include .md, .markdown, .mdown, .mkd, and .mdx; MDX components are not executed. Online documents, interactive scripts, external fonts, and math typesetting are outside the current preview scope.
