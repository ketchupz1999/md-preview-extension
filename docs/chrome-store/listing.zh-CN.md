# MD Preview

直接在浏览器中阅读本地 Markdown。

开启一次文件网址权限，之后打开 .md 文件，MD Preview 就会自动呈现排版后的正文。大纲、文件目录与常用阅读工具随手可用，所有处理都在本机完成。

主要功能

• Markdown 排版：标题、表格、引用、任务列表和代码高亮。
• 文档导航：默认显示大纲，切换到文件 Tab 浏览所在目录并搜索文件名。
• Mermaid 图表：支持时序图、流程图、状态图、ER 图等，可放大查看。
• 阅读工具：深浅主题、源码视图、文字大小设置、自动刷新和阅读位置恢复。
• 辅助预览：本地 HTML 笔记按静态页面展示，本地 CSS 与图片可以一同加载；CSS 文件提供色值预览。

纯本地运行

扩展只读文件，不上传文档，不连接开发者服务器，也不加载远程脚本、字体或图片。全部渲染库随扩展打包。外部链接仅提供复制地址，HTML 预览不执行脚本或导航。

使用方法

安装后进入扩展详情，开启「允许访问文件网址」，再用浏览器打开本地 Markdown。也可以点击扩展图标选择文件或文件夹。

⌘ / Ctrl + K：搜索文件
⌘ / Ctrl + B：收起侧栏
Esc：关闭图表预览

支持 .md、.markdown、.mdown、.mkd 和 .mdx；MDX 中的组件不会执行。面向桌面 Chrome。在线文档、交互脚本、外部字体与数学公式不在当前预览范围内。
