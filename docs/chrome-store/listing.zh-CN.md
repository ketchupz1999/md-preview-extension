MD Preview 在浏览器中自动预览本地 Markdown，适合阅读项目文档、技术笔记和个人知识库。

主要功能

• 清晰排版：标题、表格、任务列表和代码高亮。
• 文档导航：大纲定位、目录文件树与文件名搜索。
• Mermaid 图表：支持时序图、流程图等，可放大查看。
• 灵活布局：正文随浏览器缩放铺满阅读区，宽表格可横向滚动。
• 阅读工具：深浅主题、源码视图、文字大小调整、自动刷新与阅读位置恢复。
• 相关文件：HTML 静态预览支持本地 CSS 和图片，CSS 文件提供色值预览。

纯本地运行

所有处理都在本机完成。扩展只读文件，不上传文档，不加载远程脚本、字体或图片。本地保存最近的文件引用、阅读位置和偏好，不持久缓存文档正文。外部链接只提供复制地址，HTML 预览不执行脚本或导航。

开始使用

安装后进入扩展详情，开启「允许访问文件网址」，再用浏览器打开本地 Markdown。也可以点击扩展图标选择文件或文件夹。

界面使用简体中文，文档可以包含任意语言。在线文档、交互脚本和数学公式不在支持范围内。
