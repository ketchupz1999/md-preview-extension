## Data disclosures

The extension processes local document contents, file references, and reading positions on the device. Nothing is transmitted to the developer or third parties. The [review notes](review-notes.md) explain the form categories and permission scope; the [privacy policy](../PRIVACY.md) is the user-facing disclosure. Keep the dashboard declarations consistent with both.
